# GoodZone Live — Android

Простой Android-клиент сайта https://goodzone.live/ на Kotlin + WebView.

## Сборка
1. Установите Android Studio (актуальную версию) и Android SDK 35.
2. Откройте папку `GoodZoneLiveAndroid` в Android Studio.
3. Дождитесь синхронизации Gradle.
4. Подключите Android-телефон с USB debugging или создайте эмулятор.
5. Нажмите Run.

Для APK: **Build → Build Bundle(s) / APK(s) → Build APK(s)**.

## Возможности
- Открывает GoodZone Live внутри приложения.
- JavaScript, DOM Storage и cookies включены для работы сайта и авторизации.
- Разрешено воспроизведение медиа после действий пользователя (настройка WebView также допускает autoplay).
- Полноэкранное видео, поворот экрана и кнопка Back.
- Внешние нестандартные ссылки передаются соответствующим приложениям.

## Важно
Это WebView-клиент, а не независимый видеоплеер. Работа конкретных трансляций зависит от реализации плеера сайта, доступности потоков, авторизации, DRM и ограничений самого сайта. Если сайт требует DRM/кодеки, которые WebView устройства не поддерживает, отдельные эфиры могут не воспроизводиться. Для публикации в Google Play проверьте разрешение владельца сайта на использование его сервиса и бренда.
